PIXEL BRAWL — WINDOWS VERSION

QUICK START
1. Extract this ZIP file to a folder.
2. Double-click pixel_brawl_windows.html.
3. If asked, open it with Microsoft Edge or Google Chrome.
4. Play using the keyboard controls shown below.

CONTROLS
Player 1 (Blue): A/D move, W jump, F punch, G kick
Player 2 (Red): Left/Right move, Up jump, K punch, L kick

This version runs in your browser and does not require installation or an internet connection.
It is not a standalone .EXE installer yet.
